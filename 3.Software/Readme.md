# UniProgrammer (3.Software)

Frontend + Tauri backend workspace.

- Frontend: **Tauri 2** + **Vue 3** + **TypeScript** + **Pinia**
- Backend: Rust in `src-tauri`
- UI build: `npm run build`
- Lint: `npm run lint` / format: `npm run format`
- Full desktop build: `npm run tauri build`

See repository root `README.md` for project-level documentation.
